# MiniFactory

Мобильный tycoon-симулятор фабрики (Kotlin, Android Views, собственный 2.5D-рендерер на Canvas).

## Сборка через GitHub Actions
1. Создайте репозиторий на GitHub и загрузите всё содержимое этой папки (включая `.github/`).
2. Откройте вкладку **Actions** → workflow **Build MiniFactory** (запускается сам при push в `main`/`master`, либо вручную: *Run workflow*).
3. Когда сборка завершится, откройте запуск и скачайте артефакт **MiniFactory-debug-apk** (внутри `app-debug.apk`).
4. Установите APK на телефон (разрешите установку из неизвестных источников).

## Управление
- Палец — двигать камеру, два пальца — масштаб.
- Нижняя панель — выберите станок и тапайте по пустым клеткам; «Поворот» меняет направление.
- Тап по станку — меню: поворот, перемещение, улучшение, продажа.
- Склад — продажа продукции, Задания — контракты и карьера, Наука — глобальные улучшения.
